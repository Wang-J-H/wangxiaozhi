# 工作区文件管理                                                                                                                                                             

## 背景

你生成的交付物（图片、PDF、PPT、HTML、Excel 等）需要展示给用户。默认情况下：

- 文件保存到 `outputs/` 目录（每个对话线程私有）
- 调用 `present_artifacts` 注册后，前端会显示交付物卡片
- 卡片右下角有 **"保存到工作区"** 按钮，用户手动点击可将文件保存到 `/个人工作区/Saved Artifacts/`

## 标准流程（默认行为）

1. 用 `write_file` 或脚本将结果文件写入 `{VIRTUAL_PATH_OUTPUTS}` 目录
2. 立即调用 `present_artifacts` 注册该文件
3. 前端展示交付物卡片，用户自行点击"保存到工作区"

## 自定义存放路径（用户指定目录时）

当用户要求"把文件放到工作区的某个文件夹"时：                                                                                                                                 

1. 先用 `write_file` 或脚本将文件保存到 `{VIRTUAL_PATH_WORKSPACE}/<用户指定路径>/` 下
2. 再调用 `present_artifacts` 注册该文件，确保前端展示交付物卡片

注意：
- 工作区路径对用户可见，用户可以在工作区 UI 中新建文件夹
- 用户可以在对话中指定任意路径，例如"保存到 /个人工作区/项目报告/二期/"
- 也可以让 AI 在工作区新建文件夹后再保存
- 如果用户没有指定路径，走默认流程（outputs + 保存到工作区按钮）
